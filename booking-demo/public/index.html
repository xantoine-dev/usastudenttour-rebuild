Objective

Demo Booking Engine Proposal (Netlify-Friendly)

A clean, believable booking flow that mirrors a PHP/MySQL architecture, but runs serverlessly for demo.

What Bill should feel

  • Understands booking flows and ownership.
  • Complexity made simple.
  • No PCI scope; payment later.

Stack

  • HTML + Tailwind + vanilla JS
  • Netlify hosting + functions (Node)
  • PHP parity: maps 1:1 to PHP/MySQL later

Flow you will see

  1. Tour selection: destination, date, group size.
  2. Availability & pricing: calls a Netlify Function; applies group discounts; live price update.
  3. Guest info: name, contact, school/group.
  4. Confirmation: booking reference ID; email simulated.
